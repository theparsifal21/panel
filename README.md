# PANEL

Personal manhwa and comic reader for mobile and desktop.

[Open PANEL](https://theparsifal21.github.io/panel/)

## Project goals
- Organize a digital reading library and track chapters.
- Discover permitted chapter sources and support a self-hosted library.
- Provide a minimal reading interface.

## Deployment
Serve the repository with GitHub Pages from `main` and the root directory. External chapter sources and backend services may require separate configuration. Automatic chapter discovery and live availability are not guaranteed.
